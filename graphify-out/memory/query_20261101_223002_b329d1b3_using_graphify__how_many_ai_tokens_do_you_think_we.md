# Q: using graphify, how many ai tokens do you think we saved?

## Answer

Expanded from graph vocabulary: [graphify, query, knowledge, project, report]. graphify benchmark estimates a naive full-corpus query at ~14,133 tokens and an average graph query at ~2,964 tokens, for about 11,169 tokens saved per question (about 79% fewer; roughly 4.8x reduction). This is an estimate based on the benchmark, not a measured total across actual user queries.
